# Protocol

Open Grok with: Diary YYYY-MM-DD
Commit notes here with no secrets.

Hunt: `/pick` → live `/scope` → one hop → `/log`.
Abandon: `/hold <id> <reason>` → diary the lesson → new `/pick`. Do not re-queue a held desk.

Lane: IDOR / BAC (Broken Access Control) / XSS.
You submit. Bot never Sends.
